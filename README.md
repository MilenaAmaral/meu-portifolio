## 👩‍💻 Sobre o projeto

Este é meu portfólio profissional desenvolvido para apresentar minha trajetória, projetos e habilidades na área de tecnologia.

Sou estudante de **Engenharia de Software** e estou realizando uma transição de carreira da área da saúde para desenvolvimento de software.

Minha experiência como **Técnica de Enfermagem** contribuiu para desenvolver habilidades como responsabilidade, atenção aos detalhes, trabalho em equipe e resolução de problemas — competências que aplico na minha evolução como desenvolvedora.
